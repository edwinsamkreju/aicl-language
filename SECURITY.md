# Security policy

Copyright © 2026 Edwin Sam K Reju. All rights reserved.

AICL is an experimental language prototype. Do not use it to execute untrusted programs in a production environment.

The current reference interpreter implements only pure scalar/list operations and has no AICL-level filesystem, network, process, credential, or device APIs. It includes execution-step and call-depth budgets, but these are prototype safeguards, not a substitute for process isolation or a hardened sandbox.

Report suspected vulnerabilities privately to the repository maintainer once a security contact is configured. Do not publish exploit details before a fix is available.
